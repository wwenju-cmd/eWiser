Paragraph-level Bilingual Translation — Privacy Policy

概述 Summary

eWiser 是一款网页双语翻译浏览器扩展。我们的核心隐私承诺非常简单：

  • 我们不收集任何数据。 扩展没有自己的服务器，开发者无法访问你的任何信息。
  • 一切数据保存在你的浏览器本地。 API 密钥、设置和译文缓存均存储于本地，仅由扩展自身读写。

English: eWiser is a browser extension for paragraph-level bilingual translation. The developer does not collect, store, or transmit any user data. All settings (including API keys) and cached translations are stored locally in your browser and are never sent to the developer.

数据如何流动 Data Flow

当你触发翻译时，扩展的工作方式如下：

  • 扩展读取当前网页中的段落文本（仅在你主动点击翻译按钮、右键菜单或按下快捷键 Alt+T 时）；
  • 这些段落文本被发送到你自己配置的大模型 API 接口（如 Kimi、DeepSeek、智谱 GLM 或你自定义的 OpenAI 兼容接口）用于生成译文；
  • 返回的译文插入到原文下方，并缓存到本地存储以加速下次访问。

除上述「发送给你自己配置的 AI 服务商」之外，扩展不会向任何第三方发送数据，不存在任何广告、追踪、分析或遥测。

English: When you trigger translation, paragraph text from the current page is sent only to the AI API endpoint you have configured (e.g. Kimi, DeepSeek, Zhipu GLM, or a custom OpenAI-compatible endpoint). The extension communicates with no other servers. There are no ads, no analytics, and no tracking of any kind.

视频翻译（可选功能）：当你在视频页面勾选「视频翻译」并点击字幕浮层的「▶ 开始」后：

  • 若视频自带字幕轨，扩展仅读取字幕文本并按上述流程翻译，不采集任何音频；
  • 若视频无字幕轨，扩展通过 tabCapture 捕获当前标签页的音频，实时发送至你自己填写凭证的讯飞实时语音转写（RTASR）接口进行语音识别，识别文本再按上述流程翻译；
  • 音频流仅在识别会话期间实时传输，不录音、不落盘、不保存；点击「■ 停止」或取消勾选即终止采集。

English (video translation, optional): When you enable "Video Translation" on a video page and press ▶: if the video has caption tracks, only caption text is read — no audio is captured. If not, tab audio is streamed in real time to the iFlytek RTASR endpoint whose credentials you provided, solely for speech recognition. Audio is never recorded or stored, and capture stops the moment you stop the session.

本地存储 Local Storage

扩展在你的浏览器中保存：

  • 模型服务商配置：API Base URL、API Key、模型名称、目标语言等；
  • 译文缓存：已翻译页面的段落译文，用于加速重复访问。

以上数据全部保存在浏览器本地（chrome.storage），清除浏览器数据或卸载扩展即被彻底删除。

权限用途 Permissions

  • host_permissions / scripting：在你当前浏览并触发翻译的网页中注入段落切分与译文展示脚本；
  • storage / unlimitedStorage：本地保存配置与译文缓存；
  • activeTab / contextMenus：通过工具栏按钮、右键菜单「翻译本页」触发当前标签页的翻译；
  • tabCapture：仅当你在视频页面主动开始「视频翻译」且视频无字幕轨时，捕获当前标签页音频用于实时语音识别；
  • offscreen：在离屏文档中运行音频处理（AudioWorklet），把采集的音频流转发至语音识别接口。

扩展不会在后台读取你没有主动翻译的页面，也不会在你未开始视频翻译时采集任何音频。

第三方服务 Third-party Services

译文由你自行配置的大模型服务商生成；视频语音识别由你自行填写凭证的讯飞实时语音转写服务完成。你与这些服务商之间的数据处理受其自身隐私政策约束，请在对应平台查阅（如月之暗面、深度求索、智谱、讯飞开放平台等的服务条款与隐私政策）。
